# MIA Poster Design

MIA Poster Design is an owner-operated meeting bot for MeetStream. A participant describes an event aloud, activates the assistant with a wake phrase such as `Hey MIA`, and asks it to create posters. The bot sends the brief to Canva and returns up to three editable Canva candidates in meeting chat.

The project is intentionally small:

- MeetStream joins the meeting, transcribes speech, detects wake words, runs the language model, and posts chat responses.
- This Node.js app validates the saved MeetStream agent, exposes a private Canva MCP bridge, receives lifecycle webhooks, and removes the bot during shutdown.
- Canva generates the designs in the Canva account authenticated on the machine running this project.

## Important limitation

This is an **owner-only Canva bot**. Every generation uses one locally authenticated Canva account. It is suitable for a personal assistant, demonstration, or trusted internal deployment. It is not a multi-user OAuth implementation.

The Canva OAuth session is stored outside the repository in `$HOME/.mcp-auth` (`$env:USERPROFILE\.mcp-auth` on Windows). Never commit or share that directory.

## Request flow

```text
Participant speech
  -> MeetStream + Deepgram nova-3
  -> 30-second wake-word window
  -> OpenAI gpt-4.1-mini
  -> private /mcp bridge in this app
  -> Canva generate-design
  -> Canva links and thumbnails in meeting chat
```

## Prerequisites

Install or prepare all of the following:

- Docker Desktop, running before you use Docker Compose.
- Node.js 20 or newer and npm.
- A MeetStream account and API key.
- A saved MeetStream MIA Agent ID.
- A Google Meet or other supported meeting URL that the bot may join.
- An ngrok account and auth token.
- A Canva account with available design-generation credits.

The project does not require a local OpenAI key. MeetStream owns the model integration.

## Environment configuration

Create your private environment file:

```powershell
Copy-Item .env.example .env
```

On macOS or Linux:

```bash
cp .env.example .env
```

Edit `.env` and replace every placeholder:

| Variable | Required | Meaning |
| --- | --- | --- |
| `MEETSTREAM_API_KEY` | Yes | API key used to read the saved agent and create or remove bots. |
| `MEETSTREAM_AGENT_CONFIG_ID` | Yes | ID of the saved MIA agent that this project validates and deploys. |
| `MEETING_LINK` | Yes | Complete HTTPS meeting URL. |
| `NGROK_AUTHTOKEN` | Yes | Creates the public HTTPS webhook and MCP endpoint. |
| `PORT` | No | Local HTTP port. Defaults to `3000`. |
| `ADAPTER_ONLY` | No | `true` starts only the Canva bridge for first-time MeetStream setup. Normal meetings use `false`. |

`.env` is ignored by Git and Docker builds. Do not paste its contents into an issue, commit, screenshot, or support message.

## Command guide

| Command | When to use it |
| --- | --- |
| `npm install` | Once after cloning, and again if `package-lock.json` changes. |
| `npm run check:canva` | During first setup, after changing Canva accounts, or when Canva authentication fails. It verifies the tool without generating a design. |
| `npm run show:mcp-credential` | Prints the private `Authorization` header value required by the saved MeetStream MCP server. Do not share the output. |
| `npm test` | Verifies configuration validation, bridge restrictions, webhook handling, and graceful bot removal. |
| `docker compose up --build` | Recommended first meeting run and every run after source or dependency changes. |
| `docker compose up` | Normal later run when the Docker image is already built. This avoids most build output. |
| `npm start` | Local development alternative to Docker. Run `docker compose down` first. |
| `docker compose down` | Stops a detached bridge/container or clears Docker before local development. |

Docker and `npm start` execute the same `src/index.js` application. Docker is the recommended plug-and-play path because it pins Node.js 20 and mounts the Canva OAuth directory consistently.

Do not run Docker and `npm start` together. Both listen on the same port, so the second process fails with `EADDRINUSE`.

## First-time installation

### 1. Install packages and authenticate Canva

```powershell
npm install
npm run check:canva
npm test
```

The Canva check may open a browser. Sign in to the Canva account that should own designs generated by this bot and approve the requested access. A successful check prints:

```text
Canva bridge verified: generate-design
```

### 2. Start the bridge without deploying a meeting bot

MeetStream must be configured with a public MCP URL before the full bot can start.

Windows PowerShell:

```powershell
$env:ADAPTER_ONLY='true'
docker compose up --build -d
docker compose logs --tail 20
```

macOS or Linux:

```bash
ADAPTER_ONLY=true docker compose up --build -d
docker compose logs --tail 20
```

Copy the URL from this line:

```text
Bridge ready: https://your-ngrok-domain.example/mcp
```

The complete URL, including `/mcp`, is required. A free ngrok URL may change after a restart.

### 3. Configure the saved MeetStream MIA agent

Open the MeetStream dashboard and configure the agent referenced by `MEETSTREAM_AGENT_CONFIG_ID`.

| Setting | Required value |
| --- | --- |
| Mode | `pipeline` |
| Model provider | OpenAI |
| Model | `gpt-4.1-mini` |
| System prompt | Copy the complete exported `SYSTEM_PROMPT` from `src/deployBot.js` |
| Response type | `chat` |
| Response modality | `chat` |
| Transcriber provider | Deepgram |
| Transcriber model | `nova-3` |
| Wake words | Enabled with the six phrases listed below |
| Wake timeout | `30` seconds |
| MCP URL | Public `/mcp` URL printed by the bridge |
| MCP timeout | `90` seconds recommended |
| Allowed tools | Only `generate-design` |

Configure these wake phrases:

```text
hey mia
okay mia
ok mia
hey assistant
okay assistant
hey bot
```

Generate the private MCP header value locally:

```powershell
npm run show:mcp-credential
```

In MeetStream, add:

```text
Header name:  Authorization
Header value: Bearer <generated-value>
```

Paste the complete output from the command as the header value. Fetch the MCP tools, select only `generate-design`, and save the agent.

### 4. Start the full bot

The adapter-only container must be recreated with full mode enabled.

Windows PowerShell:

```powershell
$env:ADAPTER_ONLY='false'
docker compose up --build
```

macOS or Linux:

```bash
ADAPTER_ONLY=false docker compose up --build
```

If the public ngrok URL changed, startup intentionally stops with an MCP URL mismatch. Update the saved MeetStream MCP URL to the newly printed `/mcp` address and run the command again.

## Normal meeting workflow

After the first successful setup:

1. Put the current meeting link in `.env`.
2. Make sure Docker Desktop is running.
3. Start the bot in the foreground:

   ```powershell
   docker compose up
   ```

4. Wait for these messages:

   ```text
   Bridge ready: https://.../mcp
   Agent ready: pipeline · gpt-4.1-mini · chat · Deepgram nova-3 · wake 30s
   Bot joining meeting
   Waiting to be admitted
   Bot joined the meeting
   Bot is listening
   ```

5. Admit `MIA Poster Design Bot` from the meeting waiting room.
6. Speak the request aloud. MIA listens to meeting audio and replies in meeting chat.
7. Leave the terminal running for the entire meeting.
8. Press Ctrl+C once when finished and wait for `Bot removed; shutdown complete`.

Use `docker compose up --build` instead of `docker compose up` after changing project code or dependencies.

## How to talk to MIA

MIA does not respond to every sentence. Begin with a wake phrase, then provide the request within the 30-second listening window. Speaking the wake phrase and request in one continuous sentence is most reliable.

Recommended test request:

```text
Hey Assistant, create three birthday poster concepts for tomorrow at 6 PM at my house. Use bright playful colors, balloons, and confetti. Use sensible defaults for anything missing and generate now.
```

More detailed request:

```text
Hey MIA, create three poster concepts for Aarav's seventh birthday on 10 August 2026 at 6 PM at our house. Use the exact headline "Aarav Turns Seven" and message "Everyone is welcome." Make it playful and kid-friendly with bright blue, yellow, and pink, rounded typography, balloons, confetti, clear hierarchy, and generous safe margins. Generate now.
```

Useful prompting rules:

- Say the request aloud; the assistant returns its answer in meeting chat.
- Include the event type. Other details are optional.
- Saying `create`, `generate`, or `proceed` tells MIA not to wait for more information.
- Say `use sensible defaults for anything missing` when you do not care about optional details.
- If more than 30 seconds passes, start again with a wake phrase.
- For revisions, state what stays fixed and what changes.

Revision example:

```text
Hey MIA, keep the date, time, venue, and wording. Change the theme to a space adventure and regenerate three designs.
```

## Expected result

When successful, MIA posts up to three Canva candidate links and thumbnail links in meeting chat. Open a Canva link to review and continue editing the design.

If MIA posts a Canva quota or credit-limit message, the full application flow worked. The connected Canva account could not perform another generation at that time.

## Graceful shutdown

For a foreground `docker compose up` or `npm start` process:

1. Press Ctrl+C once.
2. Keep the terminal open while removal is pending.
3. Wait for:

   ```text
   Removing bot
   MeetStream reports the bot stopped
   Bot removed; shutdown complete
   ```

Ctrl+C in `docker compose logs -f` only stops log viewing; it does not stop a detached container. Run `docker compose down` to stop a detached bridge or bot.

## Local development without Docker

Docker is recommended for users. Contributors may run the same application directly:

```powershell
docker compose down
npm start
```

Local mode still requires a valid `.env`, Canva OAuth, the saved MeetStream configuration, and port `3000` to be free. Keep the terminal open and use Ctrl+C for graceful bot removal.

## Switch the Canva account

Canva access tokens are OAuth credentials, not credits that can be manually added to `.env`. To use another Canva account, stop the bot and preserve the existing OAuth directory as a recoverable backup.

Windows PowerShell:

```powershell
docker compose down
Rename-Item -LiteralPath "$env:USERPROFILE\.mcp-auth" -NewName ".mcp-auth.backup-$(Get-Date -Format yyyyMMdd-HHmmss)"
npm run check:canva
```

macOS or Linux:

```bash
docker compose down
mv "$HOME/.mcp-auth" "$HOME/.mcp-auth.backup-$(date +%Y%m%d-%H%M%S)"
npm run check:canva
```

Sign into the desired Canva account when the browser opens. If the browser automatically selects the old account, sign out of Canva first. After verification succeeds, start the bot again with `docker compose up`.

Changing Canva accounts does not change the MeetStream MCP `Authorization` header. That header changes only when `MEETSTREAM_API_KEY` changes.

## Troubleshooting

### `EADDRINUSE: address already in use :::3000`

Another process already owns port `3000`. The usual cause is running Docker and `npm start` together.

```powershell
docker compose down
npm start
```

Use only one startup method.

### Bot says it is listening but does not respond

- Confirm your microphone is unmuted.
- Speak rather than typing the request into meeting chat.
- Use an exact wake phrase such as `Hey Assistant`.
- Put the wake phrase and complete request in one sentence.
- Repeat the wake phrase if more than 30 seconds has passed.
- Wait up to 90 seconds for Canva generation.

### Canva quota or credit limit

This is an upstream Canva account limit, not a Docker, MeetStream, or bridge failure. Wait for Canva's limit to reset or switch to another Canva account with available generation credits.

### Agent system prompt is out of date

Copy the current `SYSTEM_PROMPT` from `src/deployBot.js` into the saved MeetStream agent. Startup requires the saved prompt to match so old question-heavy behavior cannot silently return.

### MCP endpoint mismatch

The ngrok URL changed. Copy the new printed URL ending in `/mcp`, replace the saved MeetStream MCP URL, fetch tools again, allow only `generate-design`, and save.

### Canva authentication or tool check fails

Run:

```powershell
npm run check:canva
```

If the OAuth session belongs to the wrong account, follow the account-switch procedure above.

### `npm` is blocked by PowerShell execution policy

Use the Windows command shim:

```powershell
npm.cmd install
npm.cmd test
```

## Security and open-source publishing

- Never commit `.env`, `.mcp-auth`, or `.mcp-auth.backup-*`.
- Never publish the output of `npm run show:mcp-credential`.
- Rotate any credential accidentally pasted into logs, screenshots, issues, or commits.
- Keep `generate-design` as the only allowed MCP tool unless the project scope is intentionally expanded.
- Review `git status` before every public commit.

## Project checks

These checks do not deploy a meeting bot:

```powershell
npm test
npm run check:canva
```

`npm test` is entirely local. `npm run check:canva` contacts Canva and may open OAuth, but it lists and verifies tools rather than generating a poster.
